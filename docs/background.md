# DSL MUD background

## What DSL means

`DSL MUD` refers to **Dark and Shattered Lands**, often abbreviated **DSL**.

It is a long-running fantasy MUD: a text-based online multiplayer role-playing game where players connect to a server, type commands, explore rooms, fight, level up, and interact with other players.

## Connection

```text
dsl-mud.org 4000
```

## Notes from the initial lookup

- DSL stands for **Dark and Shattered Lands**.
- Public MUD listings describe it as a fantasy-themed MUD.
- Public listings showed it as founded in 1996.
- The official play page listed the connection address as `dsl-mud.org` on port `4000`.

## Client choice from the conversation

For macOS command line use, the chosen client was **TinTin++**.

Alternative clients mentioned:

- **Mudlet** — good GUI MUD client, not command-line focused.
- **TinyFugue** — terminal MUD client, but older and less appealing as the first choice.

Final recommendation:

```text
TinTin++ + macOS Terminal/iTerm2 + ~/.tintin/dsl.tin
```
