# DSL research resources

## Shattered Archive

URL:

```text
https://shatteredarchive.com
```

Shattered Archive is a fan archive for **Dark and Shattered Lands**. The homepage says the site aggregates knowledge learned over decades of play. It is meant to help players discover that something exists, then use in-game resources to build their character's story.

Useful sections visible from the homepage:

- Directions
- Items
- Rooms
- Ability Groups
- Character Creation Simulator
- Damage Calculator
- Beastiary
- Races, including Yinn
- Classes, including Mage and Mage subclasses
- Class Trainers
- Player guides and books
- AGL fight logs
- Toasts
- Scripting
- External DSL links

## Why it matters for this repo

This resource can answer questions the raw in-game area list cannot answer by itself, especially:

- where an area entrance is located;
- directions by continent;
- item lookup;
- room lookup;
- Yinn race details;
- Mage class details;
- class trainer locations;
- public fight-log references;
- scripting examples.

## Current caution

Some subpages may not load cleanly through all tools, but the site homepage exposes enough index information to use it as a source to query manually or through a browser.
